# 📝 Smart Memo

ระบบออกเอกสารแจ้งเพื่อทราบ (Memo) อัตโนมัติ ช่วยให้การจัดทำเอกสารเป็นเรื่องง่าย รวดเร็ว และเป็นมาตรฐาน เพียงกรอกข้อมูลตามช่องที่กำหนด ก็สามารถพรีวิว ดาวน์โหลด พิมพ์ หรือส่งต่อได้ทันที

---

### 🌟 คุณสมบัติเด่น (Features)
* ✍️ **ใช้ง่าย:** กรอกข้อมูลตามหัวข้อเพื่อสร้างเอกสารได้ทันที
* 👁️ **พรีวิว realtime:** ตัวอย่างเอกสารอัปเดตตามข้อมูลที่กรอกทันที
* 📥 **ดาวน์โหลด & พิมพ์:** รองรับการบันทึกเป็น PDF หรือสั่งพิมพ์ได้จากหน้าเว็บ
* 📱 **รองรับทุกอุปกรณ์:** ใช้งานได้ทั้งบนคอมพิวเตอร์และมือถือ
